# Reliable Cell Type Classification in Mouse Brain scRNA-seq

This repository contains the reproducible R code accompanying the paper:

**Machine Learning for Cell Type Classification in Single-Cell RNA Sequencing: Grouped Validation and Open-Set Evaluation**

The study was accepted at the II Escola Regional de Aprendizado de Máquina e Inteligência Artificial da Região Sul (ERAMIA-RS 2026).

Using 3,005 mouse cortex and hippocampus cells from Zeisel et al. (2015), the analysis evaluates conventional classifiers under leakage-free repeated cross-validation, technical-group-blocked validation, probability calibration, selective classification, leave-one-cell-type-out open-set recognition, and class-conditional conformal prediction.
